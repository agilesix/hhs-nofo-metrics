# Security policy

Do not include credentials, unpublished NOFO content, reviewer information, or
other sensitive material in a public issue.

Report a vulnerability through GitHub private vulnerability reporting when it
is available for this repository. If that feature is unavailable, open a
minimal issue asking a maintainer for a private reporting channel without
including the sensitive details.

Security support applies to the latest released package version. Reports should
identify the affected version, the input class needed to reproduce the issue,
and the impact without attaching private source documents.
